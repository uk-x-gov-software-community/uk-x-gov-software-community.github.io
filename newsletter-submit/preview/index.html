How to create the GitHub Issue

  1. Copy the issue content using the button above.
  2. Open GitHub to create a new issue (opens in a new tab). The issue body will be pre-filled if your browser supports it.
  3. Set the issue title to something like Newsletter Submission – [your name].
  4. Paste the copied content into the issue body if it is not already there.
  5. Click Submit new issue.
